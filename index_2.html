Signal & Script
A running log of two parallel skill sets: reading attacker behaviour on TryHackMe, and writing Python on Mimo. Posted as each concept lands, not polished after the fact.

I hold CompTIA Security+ and A+, and everything here is self-directed: no bootcamp, no course cohort, just consistent daily practice.

This site is where that practice gets written down properly. TryHackMe entries cover the frameworks and hands-on rooms behind detection and incident response; Python entries track the fundamentals as I build them up on Mimo, aimed at scripting the kind of repetitive analysis work security tooling relies on.
